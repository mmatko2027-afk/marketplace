# ClickBack

## Опис проєкту

**ClickBack** — REST API платформи оголошень для купівлі та продажу електроніки. Проєкт забезпечує роботу з користувачами, категоріями товарів, оголошеннями та обраними товарами.

## Основні можливості

- **Користувачі (`User`)** — зберігання інформації про користувачів.
- **Категорії (`Category`)** — групування оголошень за категоріями.
- **Оголошення (`Listing`)** — зберігання інформації про товари, їхні описи, ціни та категорії.
- **Обране (`Favorite`)** — зв’язок між користувачами й оголошеннями, які вони додали до обраного.
- **Повідомлення (`Message`)** — модель для зберігання повідомлень між користувачами.

## Робота з оголошеннями

API передбачає роботу з оголошеннями, зокрема отримання даних, фільтрацію, сортування та посторінкове виведення результатів, якщо відповідні ендпоїнти реалізовані.

Під час роботи з даними необхідно враховувати зв’язки між оголошеннями, категоріями та користувачами.

## Технології

- C#
- ASP.NET Core
- .NET 10
- Entity Framework Core
- SQLite
- REST API
- Swagger / OpenAPI

## Архітектура

Проєкт має багаторівневу структуру:

- `Marketplace.Api` — HTTP-ендпоїнти та обробка запитів.
- `Marketplace.Application` — прикладна логіка.
- `Marketplace.Domain` — сутності предметної області.
- `Marketplace.Infrastructure` — робота з базою даних та інфраструктурними компонентами.
